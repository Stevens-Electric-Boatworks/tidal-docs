
# Tidal Telemetry Documentation

Welcome to the TidalDocs repository. 

To get started, download MkDocs, Material for MkDocs, and a required plugin:

```bash
pip install mkdocs
pip install mkdocs-material
pip install mkdocs-open-in-new-tab
```

Then, clone the repository, and run the local preview website:
```bash
git clone https://github.com/Stevens-Electric-Boatworks/tidal-docs
cd tidal-docs/
mkdocs serve --livereload
```

To learn more, read the full documentation at [docs.stevenseboat.org](https://docs.stevenseboat.org)
